Authentication & Setup

Secure login, password encryption, and environment configuration
01 Encrypt Password One-time setup — creates an encrypted .epw file

EPM Automate requires an encrypted password file (.epw) for unattended script execution. Run this once to generate it. Never store plain-text passwords in scripts.

encrypt-password.bat Windows
:: Encrypt your EPM Cloud password into a .epw file
:: Run this once — the .epw file is used by all other scripts

@echo off
set EPM_URL=https://your-environment.epm.us-ashburn-1.ocs.oraclecloud.com
set EPM_USER=your_service_account@company.com
set EPW_FILE=C:\EPMScripts\epm_credentials.epw

epmautomate encrypt YourPassword123 YourEncryptionKey %EPW_FILE%
echo Password encrypted to: %EPW_FILE%
encrypt-password.sh Linux / Mac
#!/bin/bash
# Encrypt EPM Cloud password — run once per environment
EPM_URL="https://your-environment.epm.us-ashburn-1.ocs.oraclecloud.com"
EPW_FILE="/opt/epm/credentials.epw"

epmautomate encrypt "YourPassword" "EncryptionKey" $EPW_FILE
echo "EPW file created: $EPW_FILE"
02 Login / Logout Wrapper Reusable login block used across all scripts

A reusable login pattern that reads environment variables for portability across dev/test/production pods.

login-wrapper.bat Windows
:: Reusable login/logout wrapper
:: Set these environment variables before running any EPM Automate script

set EPM_URL=https://your-environment.epm.us-ashburn-1.ocs.oraclecloud.com
set EPM_USER=service_account@company.com
set EPM_DOMAIN=your_identity_domain
set EPW_FILE=C:\EPMScripts\epm_credentials.epw

:: LOGIN
epmautomate login %EPM_USER% %EPW_FILE% %EPM_URL% %EPM_DOMAIN%
if %ERRORLEVEL% NEQ 0 (
    echo ERROR: Login failed. Check credentials and URL.
    exit /b 1
)

:: ... your commands here ...

:: LOGOUT
epmautomate logout
echo Script completed successfully.

Pipeline Orchestration

Run FDMEE / Data Exchange pipelines end-to-end
03 Run Full Data Pipeline End-to-end pipeline: extract → load → calc

Runs a complete FDMEE data pipeline — connects to source ERP, extracts data, imports into EPM, and triggers post-load calculations. Used in production for daily AP invoice loads and actuals pipelines.

Tip: Always check job status after runDataRule — it returns immediately; use checkJobStatus in a loop to wait for completion.

run-pipeline.bat Windows
:: Run a full FDMEE data pipeline with status monitoring
@echo off
setlocal

set PIPELINE_NAME=PIPAPCIGJAE
set PERIOD=Nov-26
set LOAD_MODE=REPLACE
set IMPORT_MODE=STORE_DATA

call login-wrapper.bat

echo Running pipeline: %PIPELINE_NAME% for period %PERIOD%
epmautomate runDataRule %PIPELINE_NAME% %PERIOD% %PERIOD% %LOAD_MODE% %IMPORT_MODE%

if %ERRORLEVEL% NEQ 0 (
    echo PIPELINE FAILED. Check EPM job console.
    epmautomate logout
    exit /b 1
)

echo Pipeline completed. Running post-load calculation...
epmautomate runBusinessRule "105.PPDCLC - Process Invoice"

epmautomate logout
echo Done.
04 Daily Scheduled Orchestration Full daily run: metadata + data + calc + export

Production daily orchestration script — runs the full sequence: import metadata, load data, trigger calculations, and export results. Designed to run via Windows Task Scheduler or Linux cron.

daily-orchestration.bat Windows — Task Scheduler
:: Daily EPM orchestration — scheduled via Windows Task Scheduler
:: Schedule: 6:00 AM daily
@echo off
set LOGFILE=C:\EPMScripts\logs\daily_%date:~-4,4%%date:~-10,2%%date:~-7,2%.log

echo %date% %time% - Starting daily EPM orchestration >> %LOGFILE%

call login-wrapper.bat >> %LOGFILE% 2>&1

:: Step 1 — Import dimension metadata from flat files
echo Step 1: Importing metadata >> %LOGFILE%
epmautomate importMetadata "Import_Account.csv"  APPLICATION=PSPLAN >> %LOGFILE%
epmautomate importMetadata "Import_Dept.csv"     APPLICATION=PSPLAN >> %LOGFILE%
epmautomate importMetadata "Import_Employee.csv" APPLICATION=PSPLAN >> %LOGFILE%

:: Step 2 — Run actuals data pipeline
echo Step 2: Loading actuals >> %LOGFILE%
epmautomate runDataRule "AllActuals" Nov-26 Nov-26 REPLACE STORE_DATA >> %LOGFILE%

:: Step 3 — Trigger full recalculation
echo Step 3: Running calculations >> %LOGFILE%
epmautomate runBusinessRule "ruleset_Intraday_Full_Calculation" >> %LOGFILE%

:: Step 4 — Refresh cube
echo Step 4: Refreshing cube >> %LOGFILE%
epmautomate refreshCube PSPLAN >> %LOGFILE%

epmautomate logout >> %LOGFILE%
echo %date% %time% - Orchestration complete >> %LOGFILE%
daily-orchestration.sh Linux — Cron
#!/bin/bash
# Daily EPM orchestration — add to crontab:
# 0 6 * * * /opt/epm/scripts/daily-orchestration.sh

LOGFILE="/opt/epm/logs/daily_$(date +%Y%m%d).log"
EPM_URL="https://your-environment.epm.us-ashburn-1.ocs.oraclecloud.com"
EPM_USER="service_account@company.com"
EPW_FILE="/opt/epm/credentials.epw"
DOMAIN="your_domain"

epmautomate login $EPM_USER $EPW_FILE $EPM_URL $DOMAIN >> $LOGFILE 2>&1

epmautomate importMetadata "Import_Account.csv" APPLICATION=PSPLAN >> $LOGFILE
epmautomate runDataRule "AllActuals" Nov-26 Nov-26 REPLACE STORE_DATA >> $LOGFILE
epmautomate runBusinessRule "ruleset_Intraday_Full_Calculation" >> $LOGFILE
epmautomate refreshCube PSPLAN >> $LOGFILE

epmautomate logout >> $LOGFILE
echo "$(date) - Done" >> $LOGFILE

Metadata Management

Import and export dimension members via flat files
05 Import Metadata from Flat Files Load dimension members from CSV into EPM

Uploads generated dimension CSV files to EPM Cloud inbox, then imports them. Designed for the metadata automation pattern where a Groovy rule generates Import_* files from the source extract.

import-metadata.bat Windows
:: Import dimension metadata from flat files
:: Assumes CSV files are pre-generated by upstream Groovy/process
@echo off
set META_DIR=C:\EPMScripts\metadata

call login-wrapper.bat

:: Upload files to EPM inbox first
epmautomate uploadFile %META_DIR%\Import_Invoice.csv
epmautomate uploadFile %META_DIR%\Import_Line.csv
epmautomate uploadFile %META_DIR%\Import_Distribution.csv
epmautomate uploadFile %META_DIR%\Import_Supplier.csv

:: Import each dimension
epmautomate importMetadata "Import_Invoice.csv"      APPLICATION=CIGJAE
epmautomate importMetadata "Import_Line.csv"         APPLICATION=CIGJAE
epmautomate importMetadata "Import_Distribution.csv" APPLICATION=CIGJAE
epmautomate importMetadata "Import_Supplier.csv"     APPLICATION=CIGJAE

echo Metadata import complete.
epmautomate logout
06 Export Dimension Metadata Extract dimension members to CSV for review or migration
export-metadata.bat Windows
:: Export dimension members to CSV for review or cross-environment migration
@echo off
set OUT_DIR=C:\EPMScripts\exports\metadata

call login-wrapper.bat

epmautomate exportMetadata "Account"   "Export_Account.csv"   APPLICATION=PSPLAN
epmautomate exportMetadata "Department" "Export_Dept.csv"     APPLICATION=PSPLAN
epmautomate exportMetadata "Entity"    "Export_Entity.csv"   APPLICATION=PSPLAN

epmautomate downloadFile "Export_Entity.csv"    %OUT_DIR%

echo Metadata exported to: %OUT_DIR%
epmautomate logout

Business Rule Execution

Run Groovy rules, calc scripts, and rulesets with runtime prompts
07 Run Business Rule with Prompts Execute a rule and pass runtime prompt values

Runs a named business rule and passes runtime prompt values (e.g. year, period, scenario). Essential for rules that require user input when run manually but need automated values in scheduled runs.

run-business-rule.bat Windows
:: Run a business rule with runtime prompt values
@echo off

call login-wrapper.bat

:: Run a rule — simple (no prompts)
epmautomate runBusinessRule "105.PPDCLC - Process Invoice"

:: Run a rule with runtime prompts (key=value pairs)
epmautomate runBusinessRule "092.PPDCLC - Export and Deliver AHCS Transactions" ^
    "RTP_Year=FY26" ^
    "RTP_Period=Nov" ^
    "RTP_Region=US"

:: Run a ruleset (sequential rule execution)
epmautomate runBusinessRule "ruleset_Intraday_Full_Calculation"

epmautomate logout
08 Run All-Region Export Loop through regions and run export rule for each

Loops through all regional values and runs the export rule once per region — a common pattern for multi-region EPM applications where data is segregated by region.

run-regional-export.bat Windows
:: Run export rule for each region — US, EMEA, APAC
@echo off
set RULE=925.PPDCLC - Export Amortization Schedule_DCL

call login-wrapper.bat

for %%R in (US EMEA APAC) do (
    echo Running export for region: %%R
    epmautomate runBusinessRule "%RULE%" "RTP_Region=%%R"
    if %ERRORLEVEL% NEQ 0 (
        echo ERROR on region %%R. Continuing...
    ) else (
        echo Region %%R exported successfully.
    )
)

:: Download all export files from EPM outbox
epmautomate downloadFile "Amortization Schedule_US.csv"   C:\exports
epmautomate downloadFile "Amortization Schedule_EMEA.csv" C:\exports
epmautomate downloadFile "Amortization Schedule_APAC.csv" C:\exports

epmautomate logout

Backup & Restore (LCM)

Export and import full LCM snapshots for environment management
11 Full LCM Backup Export complete application snapshot to a dated zip

Creates a full LCM export of the application and downloads it locally with a date-stamped filename. Run before any significant deployment or migration. Used in production as a pre-go-live safety checkpoint.

backup-lcm.bat Windows
:: Full LCM backup — exports and downloads a dated snapshot
@echo off
set APP=CIGJAE
set BACKUP_DIR=C:\EPMScripts\backups
set DATE_STAMP=%date:~-4,4%%date:~-10,2%%date:~-7,2%
set BACKUP_FILE=%APP%_Backup_%DATE_STAMP%.zip

call login-wrapper.bat

echo Creating LCM snapshot: %BACKUP_FILE%
epmautomate exportSnapshot %BACKUP_FILE%

:: Wait for export to complete, then download
epmautomate downloadFile %BACKUP_FILE% %BACKUP_DIR%

echo Backup saved: %BACKUP_DIR%\%BACKUP_FILE%
epmautomate logout
12 Import LCM Snapshot Restore an LCM zip to an environment
restore-lcm.bat Windows
:: Import (restore) an LCM snapshot to an EPM environment
:: CAUTION: This overwrites existing application artifacts
@echo off
set SNAPSHOT_FILE=C:\EPMScripts\backups\CIGJAE_Backup_20261106.zip
set SNAPSHOT_NAME=CIGJAE_Backup_20261106.zip

call login-wrapper.bat

:: Upload snapshot to EPM
epmautomate uploadFile %SNAPSHOT_FILE%

:: Import the snapshot (restores all artifacts: rules, forms, dims, security)
epmautomate importSnapshot %SNAPSHOT_NAME%

echo LCM restore complete. Verify application artifacts before use.
epmautomate logout
13 Cross-Environment Migration Export from source, import to target pod

Automates the full migration cycle: backup source environment, download locally, upload to target environment, and import. Used for pod01-test → production migrations.

migrate-env.bat Windows
:: Migrate LCM from source (test) to target (prod) environment
@echo off
set SNAPSHOT=CIGJAE_Migration_%date:~-4,4%%date:~-10,2%%date:~-7,2%.zip
set LOCAL_DIR=C:\EPMScripts\migrations

:: STEP 1 — Export from SOURCE (test pod)
epmautomate login %SRC_USER% %SRC_EPW% %SRC_URL% %SRC_DOMAIN%
epmautomate exportSnapshot %SNAPSHOT%
epmautomate downloadFile %SNAPSHOT% %LOCAL_DIR%
epmautomate logout

:: STEP 2 — Import to TARGET (prod)
epmautomate login %TGT_USER% %TGT_EPW% %TGT_URL% %TGT_DOMAIN%
epmautomate uploadFile %LOCAL_DIR%\%SNAPSHOT%
epmautomate importSnapshot %SNAPSHOT%
epmautomate logout

echo Migration complete: %SNAPSHOT%
